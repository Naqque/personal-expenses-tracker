# personal-expenses-tracker 
Personal Expense Tracker:
The program store expenses, calculate total spending, filter expenses by category, and generate a readable summary report. it receives a list of lists, each list have in this order 1-Name of product. 2-cost of the product. 3-type of the product.

the program will have 4 functions so the user can do various tasks with the list

functions:
Santiago -Total: Iterates through all recorded expenses, sums up the amounts, and returns the total spending.

Christian -Filter_item: Searches through the list and returns a subset of expenses matching a specific category

Agustin -receipt: Formats and prints a clean, easy-to-read overview of all transactions along with the overall total (it can be implementing with some string format)

Ivan-new_expense: Takes the current list of expenses, adds a new entry with its description, cost, and category, and updates the list.
